# iliAI — Asistente de Estilo con Inteligencia Artificial

App móvil (React Native) + frontend web (Next.js) para gestión de armario 
virtual y generación de outfits con IA.

🔗 **Demo web:** [ili-a-ifront.vercel.app/home](https://ili-a-ifront.vercel.app/home)  
Acceso de prueba: `demo@test.com` / `123456`

## Stack
| Capa | Tecnologías |
|------|------------|
| Mobile | React Native, Expo Router, TypeScript |
| Web | Next.js, TypeScript, Styled Components |
| Estado | Context API, useReducer, custom hooks |
| Backend | Node.js, Express, MongoDB, JWT |
| IA | Google Gemini API |
| Deploy | Vercel, CI/CD |

## Funcionalidades
- 👕 Gestión de armario virtual con categorías y etiquetas de temporada
- 🤖 Generación de outfits con IA (Google Gemini API)
- 🔐 Autenticación JWT con renovación de sesión automática
- 🎨 Perfiles de usuario con colorimetría personalizada
- ⚡ Renderizado optimizado para listas de +50 prendas

## Instalación local
```bash
git clone https://github.com/AlexandruIlieDev/iliAIfront
cd iliAIfront
npm install
npm run dev
```
